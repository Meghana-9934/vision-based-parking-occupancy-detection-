# Vision-Based Parking Occupancy Detection and Protection Using Convolutional Neural Networks (CNNs)

## 📌 Project Overview

This project focuses on developing a vision-based parking occupancy detection and protection system using Computer Vision and Deep Learning techniques.

The system processes video captured from a fixed CCTV or dashcam-style camera, identifies individual parking slots, and classifies each slot as empty or occupied using a Convolutional Neural Network (CNN).

The system helps users quickly identify available parking spaces, reduces unnecessary searching time, and improves the overall utilization of parking areas.

## 🎯 Objectives

- Detect and identify individual parking slots from video frames.
- Classify parking spaces as empty or occupied using a CNN.
- Apply image preprocessing techniques to improve classification accuracy.
- Monitor parking occupancy continuously.
- Provide information about available and occupied parking spaces.
- Support monitoring of improper or unauthorized parking conditions.

## ⚙️ Working Principle

1. Video is captured using a fixed CCTV or dashcam-style camera.
2. Individual parking slots are identified from the parking area.
3. Image preprocessing techniques such as cropping, grayscale conversion, resizing, and normalization are applied.
4. The processed images are given to the CNN model.
5. The CNN classifies each parking slot as empty or occupied.
6. The system displays parking occupancy information through a user-friendly interface.

## 🧠 Machine Learning Approach

The project uses a Convolutional Neural Network (CNN) for parking occupancy classification.

A classical machine learning approach using Scikit-learn and Scikit-image is also implemented for comparison with the CNN-based approach.
